Facet Apply Assist

Fills known application-form fields from your Facet profile in a tab you opened yourself. It never submits — you read what it filled and click Submit.

The address you open Facet at. For a local install that is http://localhost:8000; for a hosted one it is your own subdomain.

What this extension can and cannot do

  • It reads your profile and your tailored resume from the address above.
  • It fills fields on Greenhouse, Lever and Workday application forms.
  • It never submits an application. There is no submit path in the code, and that is deliberate.
  • It sends nothing anywhere except to the address you entered.
